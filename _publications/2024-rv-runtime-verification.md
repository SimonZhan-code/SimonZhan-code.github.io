This case study applies runtime safety verification to a neural network controlled system: a Turtlebot navigation platform with LiDAR sensing. Using POLAR-Express, a state-of-the-art reachability analysis tool for neural network controlled systems, the work demonstrates how online reachability computation can monitor and verify safety of learned controllers during deployment.


**Authors:** Frank Yang, Simon Sinong Zhan, Yixuan Wang, Chao Huang, Qi Zhu
